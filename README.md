# 书刊27 数据要素与数据权力治理

> 政策研究·数据

## 关于本书

数据是一种新型权力：不占有你但预测你，不审查你但排序你。本书讨论数据要素与数据权力的治理框架，三层推进：数据的经济学（非竞争性、规模报酬与组合价值）、平台的数据权力结构（采集画像排序定价闭环）、治理工具箱（确权、可携带、互操作与反垄断的边界与失效条件）。以中美欧制度实践为案例。
